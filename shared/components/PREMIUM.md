# Phase 3 — Premium Components

Zero Material / Bootstrap defaults. Every component uses SyncBridge glass, Outfit, and token radii.

## Buttons
| Variant | Height | Radius | Style |
|---------|--------|--------|-------|
| Primary | 56px | 20px | Teal gradient + glow shadow |
| Secondary | 48px | 20px | Indigo subtle fill |
| Ghost | 32px min | 8px | Glass border |
| Danger | 48px | 20px | Danger subtle fill |
| Icon | 40px | 50% | Circular, glass or tint |

## Cards
- 28px radius · glass background · liquid shadow · 1px glass border
- Hero: gradient fill + primary glow

## Dialogs
- 28px radius · scale-in animation · 55% overlay · glass card body
- Actions: Ghost dismiss + Primary confirm (never system AlertDialog)

## Bottom Sheets
- Slide-up from bottom · glass surface · drag handle · 28px top radius

## Inputs / Search
- 18px radius · glass fill · primary focus ring (4px subtle)
- Search: leading magnifier icon · 44px height

## Chips & Badges
- Pill shape (999px) · semantic subtle backgrounds
- Transfer badge: cloud / LAN / WebRTC token colors

## Empty States
- Centered · hero icon in glass circle · title + description · optional CTA

## Skeletons
- Shimmer pulse · 28px card rows · no spinners for lists

## Progress
- 6px height · primary fill · 999px track · optional speed label

DeviceCard · TransferCard · ClipboardCard — see `catalog.md`
